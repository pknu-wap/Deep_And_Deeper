## 게임 소개

**Deep and Deeper**는 사이드뷰와 탑뷰를 오가며 진행하는 로그라이크 액션 게임입니다.
플레이어는 절차적으로 생성되는 던전을 탐험하고, 다양한 몬스터와 보스를 상대하며 점점 더 깊은 층으로 내려갑니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 절차적 맵 생성 | 방·문·구멍·포탈을 자동 배치하는 맵 제너레이터 |
| 사이드뷰 / 탑뷰 전환 | 전투는 사이드뷰, 탐험은 탑뷰로 진행 |
| 행동 트리 AI | 몬스터·보스가 행동 트리로 공격/이동/대기 판단 |
| 보스 전투 | 보스 처치 시 복귀 포탈 생성, 다음 층 진입 |
| 상점 시스템 | 던전 내 상점에서 아이템 구매 |
| 성장 시스템 | 레벨업 UI를 통한 능력치 강화 |
| 사운드 매니저 | BGM·효과음 통합 관리 |

## 조작

| 입력 | 동작 |
| --- | --- |
| 이동 | 좌우 이동 / 방향키 |
| 점프 | 사이드뷰 점프 |
| 공격 | 근접 공격 콤보 |
| 상호작용 | 문·포탈·상점 진입 |

## 기술 스택

- **엔진**: Unity `2022.3.9f1`
- **언어**: C#
- **AI**: MonoBehaviour Behavior Tree
- **그래픽**: 2D 픽셀아트 (Pixel Dungeon / Pixel Crawler 등)

## 시작하기

```bash
git clone https://github.com/pknu-wap/Deep_And_Deeper.git
```

1. Unity Hub에서 `Unity/` 폴더를 프로젝트로 추가
2. Unity 버전 `2022.3.9f1` 설치 후 열기
3. `Assets/UI/Main.unity` 씬에서 실행
